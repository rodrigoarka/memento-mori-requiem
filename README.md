# Memento Mori: Réquiem — Foundry VTT

Sistema de RPG de exploração metafísica para Foundry VTT 14, baseado no Manual Básico v0.8.

## Estado da publicação

**Publicação em andamento.** O repositório está inicializado, mas o código do sistema e o pacote de distribuição ainda não foram enviados. O sistema ainda não pode ser instalado a partir deste repositório.

O projeto completo está disponível no pacote ZIP preparado anteriormente. Para concluir a publicação, é necessário enviar os arquivos do ZIP à raiz do repositório, mantendo as pastas `module/`, `templates/`, `styles/`, `lang/`, `assets/`, `docs/`, `tests/` e `.github/workflows/`, e depois publicar uma Release `v0.8.1` com o arquivo de distribuição.

## Funcionalidades planejadas no pacote

Retornados, Confluências, Fissuras, domínios, entidades, Vontade determinística, Três Vozes, Distância, Âncoras, Luto, Ruptura, Deriva e Transformações.

## Compatibilidade

Foundry VTT v14. O pacote ainda precisa de um teste de integração numa instalação real do Foundry.
